# قالب سفر - WordPress Theme
# بوابة الفرص العالمية

## نظرة عامة

قالب WordPress احترافي متكامل للمنح الدراسية وفرص العمل والسفر والهجرة.

## المميزات

### التصميم
- تصميم حديث ومتجاوب (Responsive 100%)
- RTL Support كامل
- الوضع الليلي/النهاري
- أنيميشن سلسة
- Glassmorphism Effects
- Gradient جميل

### Custom Post Types
1. **المنح الدراسية** (Scholarships)
2. **فرص العمل** (Jobs)
3. **الكورسات** (Courses)
4. **التأشيرات** (Visas)
5. **الدول** (Countries)

### Taxonomies
- تصنيفات الفرص (Opportunity Categories)
- القارات (Continents)
- مستوى الدراسة (Study Level)
- نوع الوظيفة (Job Type)

### لوحة الإعدادات
- إعدادات Hero Section
- إحصائيات قابلة للتخصيص
- روابط وسائل التواصل الاجتماعي
- معلومات الاتصال
- إعدادات الفوتر

## التثبيت

1. اذهب إلى **Appearance > Themes > Add New**
2. اضغط **Upload Theme**
3. اختر ملف `safar-theme.zip`
4. اضغط **Install Now**
5. فعّل القالب

## الإعداد

1. اذهب إلى **إعدادات سفر** (في القائمة الجانبية)
2. خصص:
   - قسم البطل (Hero)
   - الإحصائيات
   - وسائل التواصل
   - الفوتر

3. اذهب إلى **Appearance > Menus**
4. أنشئ قائمة وأضفها لموقع "القائمة الرئيسية"

5. اذهب إلى **Appearance > Widgets**
6. أضف Widgets للشريط الجانبي
